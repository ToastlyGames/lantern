Rewards vault setup

For the Lanternhold owner. Open this page in your wallet app’s browser (MetaMask, Rabby…) with the wallet that holds the rewards tokens, on Robinhood Chain.

Not connected.

1. Deploy the vault

Creates the rewards vault and locks it: until the unlock date, tokens can only leave through player claims. Nobody, you included, can withdraw them. You only deploy it once: fund it in phases by sending more tokens to it any time (step 2). You’ll be its owner: you can pause claims, tune the daily limits any time (step 4), and replace the signer (it takes over 2 days after you propose it, so it’s always public first).

2. Fund it (and top it up later)

Sends tokens from this wallet into the vault. Fund in phases: send more any time, to the same vault. The game reads the vault’s balance, so a top-up raises the daily rewards from the next day (UTC).

3. Check the lock

Anyone can check it on the explorer: the vault’s unlockAt, maxDailyCap, signer and its token balance.

Deploy or enter the vault address, then tap below.

4. Tune the daily limits (any time)

If rewards drain too fast, lower these. The game’s own daily budget is set in Vercel (REWARDS_DAY_RATE); these are the vault’s safety limits on top.

5. Turn it on

In Vercel → Settings → Environment Variables: CLAIM_CONTRACT = the vault address, CLAIM_SIGNER_KEY = the signer’s private key (mark it Sensitive), and REWARDS_ON = 1. Then redeploy and open /api/health: rewards.claims should be true.
